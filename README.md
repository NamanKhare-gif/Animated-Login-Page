# Animated Responsive Login Page

A modern and responsive Login & Registration page built using HTML, CSS, and JavaScript. This project features smooth animations, interactive form elements, basic form validation, password visibility toggles, and a clean modern UI.

## ✨ Features

- 🔐 Login Form
- 📝 Registration Form
- 🔄 Smooth Login ↔ Register transition
- 🎨 Modern and clean UI
- 📱 Responsive design
- 👁️ Password visibility toggle
- ⌨️ Input focus interaction
- ✅ Basic form validation
- 🔗 Social login buttons UI
- ✨ Smooth CSS transitions and animations
- 🎯 Interactive buttons and hover effects
- 🎨 CSS custom properties for easy theme customization

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Google Fonts (Poppins)

## 🎬 Animation Flow

When the user clicks the Register button:

Register Button
      ↓
Hero Section Expands
      ↓
Login Content Moves & Fades Out
      ↓
Login Form Hides
      ↓
Hero Section Shrinks
      ↓
Registration Form Appears
      ↓
Registration Content Animates In

The transition happens without navigating to another page.
